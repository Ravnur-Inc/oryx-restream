# Ravnur Simulcast Manager

The Ravnur Simulcast Manager lets you send **one** live stream into the server
(over **SRT** or **RTMP**) and **forward** ("simulcast") it out to one or more
destinations — YouTube, Facebook, the Ravnur Media Platform, or any RTMP target —
all at the same time. You manage everything from the web UI at
`https://<your-host>/mgmt`.

The flow is always:

**Ingest** (publish in) → **Channels** (fan it out) → **Monitor** (confirm it's live and healthy).
